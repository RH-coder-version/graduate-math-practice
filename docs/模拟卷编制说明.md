# 模拟卷编制说明

这是基于本项目已整理资料的复习模拟卷，不是正式命题或考试范围承诺。每科一套固定精选卷；随机卷使用同一结构分层选题，不能理解为每道题都随机生成新数据。

## 资料与格式

- 数值分析：2020 年《高等数值分析》卷以填空、求根、矩阵分解、插值、最小二乘、数值积分、常微分方程为主。按用户需要加入复习资料中的选择题和迭代法，形成 5 道选择、5 道填空、7 道大题，分值 15+15+70。这是综合调整格式，不冒充原卷；覆盖八类主要章节，不含优化补充。
- 数理统计：2017 级《数理统计理论与方法》原卷明确填空每空 2 分共 20 分、选择 5×3 分、大题 10+10+10+10+10+15 分。本卷保留题型顺序与分数，以充分性、点估计、区间、后验、检验和正交设计为大题主线，区间题换用数据更清楚的复习题。填空按原来 3、2、2、1、2 个空分配 6、4、4、2、4 分。非参数检验、回归等专题仍需完整题库复习。
- 英语：新探索 U1—U4 A/B 篇词汇、英译汉及句式讲解资料，不含已核实的历年考试卷。综合格式为 8×2 分选择、8×3 分填空、4×10 分翻译、2×10 分句式分析。选择题为依据词汇新编的句子；翻译解答增加拆句步骤，允许合理不同译法。

## 选题与勘误

选择题查概念，填空查公式与基本运算，大题查完整解题链。随机卷按固定考点槽位选候选题，有些基础槽位固定，以保证分值和覆盖，不采用全题库无约束随机抽样。共 100 道候选题；不同随机卷难度不保证完全等值，自评分只用于复习。

- 插值基函数原选择题 C/D 重复，本卷修正 D，使 C 为唯一正确项。
- 区间题多选歧义改成“样本量变为四倍时区间长度如何变化”。
- 有效数字题明确按误差上界保证，区别于对一个具体舍入值计算实际误差。
- 显著性水平题明确为第一类错误概率的上界。
- 正交设计题按两水平总和核算：A 极差 11，B 9，C 19，D 9，应为 C>A>B=D；同步修正平时题库的对应答案。
- 公式通过本地 KaTeX 渲染检查；试卷总分、无重复、随机差异、保存恢复和答案解锁由测试验证。

## 维护与记录

运行 `python scripts/build_papers.py` 生成 `practice/papers.json`、`papers-data.js` 和三科空白卷、答案 Markdown。`practice/papers.js` 负责分层组卷和独立作答记录；用 `python scripts/update_asset_versions.py` 更新本地资源版本。

普通刷题记录与试卷记录分别保存；重新组卷不会清除旧卷。答案勘误修订会更新旧卷对应题面的解析并保留笔记、评分，建议重新核对受影响的评分。清除浏览器数据会丢失未备份记录。试卷页导出的 JSON 包含各科所有试卷记录；导入按卷号合并，已存在卷号保留本机记录。

验证命令：`node tests/papers.test.cjs`、`node tests/papers-state.test.cjs`；原刷题回归测试：`node tests/cram.test.cjs`、`node tests/cram-state.test.cjs`。
