# 原始资料下载

这里提供制作题库时使用的 PDF、Word 源文件。可以直接下载阅读、打印或自行整理，不需要安装 Python，也不需要运行刷题网页。

点击文件名进入预览，点击“下载”获取原文件；也可使用仓库的 **Code → Download ZIP** 下载整个项目，解压后在 `sources` 文件夹中找到各科资料。Word 文件不一定支持在线预览，下载后使用 Word 或 WPS 打开。

共 **31 份文件**：数值分析 13 份、数理统计 6 份、英语 12 份。原有重复文件保留；其中《数值分析2020(1).pdf》与《2020数值分析考卷.pdf》内容相同。部分文件包含参考答案或手写批注。少数乱码文件名已改为便于阅读的名称，文件内容保持不变；原文件名与 SHA-256 校验值见 [文件清单](manifest.json)。
