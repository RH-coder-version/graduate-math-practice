# 研习题库 · 数值分析、数理统计与英语

面向研一同学的本地复习网页。下载到自己的电脑后，即可按知识点或题库练习、记录解题过程，再展开 Markdown 参考答案。

## 功能

- 数值分析 364 道题、数理统计 142 道题，另有英语 148 道练习，共 654 道练习；不同试卷中的重复题保留。
- 数学 21 个知识点及英语 3 类题型的背景讲解、配套例题和分步解析。
- Markdown 题面和数学公式，参考答案默认隐藏，点击查看。
- 按题库、知识点、完成状态筛选，以及关键词搜索、随机练习。
- 标记完成或错题后自动进入下一题；取消标记不会主动跳题。
- 作答笔记自动保存在自己的浏览器；支持导出、导入学习记录。
- 清华紫配色、可收起的左侧栏，刷新后保留侧栏状态。

## 题库由哪些资料组成

面向研一上学期复习，题库由历年试卷、模拟题、期末复习题和课程讲稿整理而成。不同资料中的重复题保留，方便按原题库练习；654 道是练习条目数，并非去重后的题数。

| 科目 | 主要资料来源 | 题量与题型 |
| --- | --- | --- |
| 数值分析 | 期末复习题及答案、2018—2021 年试题扫描资料、2020／2021／2023 年试卷、2011／2014 年模拟题及其他习题汇编 | **364 道**：15 道选择、129 道填空、220 道计算／证明 |
| 数理统计 | 2017 年研究生数理统计试卷、复习空白题库、扫描版练习资料 | **142 道**：57 道选择、36 道填空、49 道计算／证明 |
| 英语 | 《新探索》U1—U4 的 A、B 篇练习与讲解，共 8 份 PDF，另附 4 份单元讲稿 | **148 道**：62 道词汇填空、35 道英译汉、51 道句式分析 |

### 数值分析

按误差与有效数字、非线性方程求根、线性方程组直接法与迭代法、插值与样条、函数逼近与最小二乘、数值微分与积分、常微分方程数值解等知识点分类。可以按知识点逐步复习，也可以选择某份试卷或模拟题练习。

### 数理统计

覆盖概率与统计基础、抽样分布、充分统计量、点估计、贝叶斯估计、区间估计、假设检验、非参数检验、方差分析、回归分析和试验设计等内容，兼顾概念辨析与计算证明。

### 英语

按词汇运用与词形变化、英译汉、长难句与篇章表达分类，也可按 U1A 至 U4B 选择题库。**51 道句式分析练习由原资料的长难句讲解改编，并非原卷中的独立试题。**英语参考答案与讲解来自原 PDF，另附 4 份完整单元讲稿的 Markdown 文本；原 PDF 词库个别笔误已对照讲稿注明校正。

### 怎样用这些资料复习

先看知识背景与配套例题，再独立作答，写完后点击查看参考答案。不会的题可以加入错题本，之后集中复习。数学部分提供 Markdown 分步解答，英语部分提供原资料答案与讲解。参考解答供复习核对；原题条件缺失或含歧义的地方已尽量注明，遇到疑问请结合课程讲义与老师讲解检查，并通过 Issue 反馈。

**本项目下载到自己的电脑运行，可离线使用。每个人的作答、错题和完成记录仅保存在自己的浏览器中，不上传 GitHub，也不与其他同学共享，请定期导出备份。**

## 在自己的电脑上使用

1. 在 GitHub 页面点击 **Code → Download ZIP**，解压整个项目；也可以使用 Git 克隆。
2. 安装 Python 3（已有 Python 或 Anaconda 可以跳过）。
3. 在项目根目录打开终端，运行：

```sh
python start.py
```

Windows 若找不到 `python`，可尝试 `py start.py`；macOS / Linux 可使用 `python3 start.py`。

浏览器会打开 [本地练习页面](http://127.0.0.1:8931/)。启动后的终端请保持打开；结束时按 Ctrl+C。启动器只监听本机。所有前端依赖已附带，无需 npm install，下载完成后可离线使用。

若提示端口被占用，先检查是否已经启动过本项目，不要重复开启。请保持使用同一个浏览器和地址。

## 英语题库怎么用

在网页顶部选择 **英语**，再选择 U1A 至 U4B 题库，或按“词汇运用与词形变化”“英译汉”“长难句与篇章表达”练习。在作答区写下答案后，点击“查看参考答案”核对。句式分析练习由讲解改编，不是原卷中的独立试题。

知识背景区域可下载 U1—U4 完整讲稿；答案区域可下载英语题库详解。“查看原页（含答案）”会显示带参考答案的资料原页。

## 界面配色

侧栏使用用户提供的西安工程大学校标，默认西安工程蓝。校标下方的配色板可展开、收起，提供 13 种纯色主题（含紫色、绿色、靛蓝、棕色、石墨灰等），颜色选择和配色板的展开状态保存在本机浏览器；校标保持原色，学习记录不受配色切换影响。

## 考前突击版

在侧栏点击 **考前突击**，按科目进入精选路线：数值分析 33 题（其中 5 题是优化补充）、数理统计 28 题、英语 18 题。按照知识点直接匹配题目，综合题优先，减少重复计算；每题注明覆盖考点、入选理由与参考用时。

覆盖清单可以按章节查看完成情况；“继续未完成”接着练，状态筛选可只看错题。与完整题库共用题号和学习记录，刷新保留突击模式及各科最近题目，答案仍需点击展开。覆盖范围以现有题库和清单为准：数值微分暂无独立代表题，英语覆盖三类方法与八篇课文来源，不代表背完所有词汇。详见 [选题依据与逐题清单](docs/考前突击选题说明.md)。

## 更新到新版

已有用户先导出学习记录备份。使用 Git 下载的同学可在项目目录运行 `git pull`；使用 ZIP 下载的同学重新下载并解压最新版，关闭旧服务后，在新版目录运行 `python start.py`。继续使用同一浏览器和 `http://127.0.0.1:8931/`，原有学习记录通常可以直接保留，也可从备份导入。

## 作答与备份

在“我的作答 / 思路记录”中输入文字即可自动保存。刷新、关闭网页后，在同一浏览器中重新打开同一地址，仍可继续作答。答案默认折叠，写完后点击“查看参考答案”。

学习记录仅存放在本机浏览器的 localStorage 中，不上传 GitHub，也不会与同学共享。无痕模式、清理浏览器数据、换浏览器或更换端口可能导致原记录不可见。请定期使用侧栏的 **导出学习记录** 保存 JSON 备份；换电脑后使用 **导入记录** 恢复。导入时，相同题号的记录会被备份中的记录覆盖。侧栏收起时，点击左上角按钮展开即可找到备份入口。

## 项目结构

```text
sources/                 按科目整理的 PDF、Word 原始资料与下载清单
start.py                 本地启动器（仅使用 Python 标准库）
practice/
  index.html             网页入口
  app.js / style.css     交互与样式
  data.js / catalog.json  题库数据
  answers.js / answers.json  Markdown 解答
  knowledge.js           知识背景与例题
  markdown/              可阅读、下载的题库和复习讲义
  assets/                原资料页面及题图
  vendor/                本地 Markdown、KaTeX 依赖
```

## 维护与纠错

发现题面或答案问题，请通过 Issue 提供科目、题库、题号、问题描述和建议修改。答案属于复习参考，部分原题条件缺失或含歧义，相应解答已注明假设，请结合课程讲义与老师讲解核对。

页面直接加载 data.js、answers.js 和 knowledge.js；只改 JSON 文件不会自动更新页面。修改题库或答案时应同步对应 JavaScript 数据，并更新 index.html 中资源的版本参数，避免缓存旧内容。修改题目 ID 会影响已有作答记录的对应关系。

题目及原始资料的权利归各自权利人所有，本项目不对这些资料授予额外许可。第三方依赖保留其原有许可证；如有资料授权问题，请联系维护者处理。

## 模拟押题卷与随机组卷（本地）

侧栏提供 **模拟押题卷** 和 **随机组卷**，顶部切换数值分析、数理统计、英语。先独立作答，点击“完成作答，解锁参考答案”，再逐题展开 Markdown 详解、自评分并标记本卷错题。

|科目|题型与分值|题数|建议用时|
|---|---|---|---|
|数值分析|选择 15、填空 15、计算与证明 70|17|150 分钟|
|数理统计|填空 20、选择 15、六道大题 65|16|120 分钟|
|英语|词汇选择 16、选词填空 24、英译汉 40、句式分析 20|22|90 分钟|

数理统计沿用 2017 级试卷结构；数值分析结合 2020 年卷计算主线与复习选择题调整题型；英语只有 U1—U4 课程资料，采用综合模拟格式。它们是考点练习卷，不是对真实试题的保证，分值和建议用时用于自测。

随机卷按固定题型、分值与考点槽位，从已核对的候选题中抽取；不会仅打乱题号，同一卷内不重复题号，部分基础题保留。笔记、交卷状态、自评分和本卷错题保存在当前浏览器，刷新可恢复；再次组卷保留历史作答。试卷记录与平时刷题记录独立，请用组卷页的 **导出试卷记录 / 导入试卷记录** 备份，侧栏原“导出学习记录”只负责平时刷题记录。关闭浏览器仍可保存；清除站点数据或换浏览器后需导入备份。

空白试卷可下载 Markdown；交卷后可下载该卷答案。固定卷文件：

- [数值分析模拟卷](practice/markdown/数值分析模拟押题卷.md) · [参考答案](practice/markdown/数值分析模拟押题卷答案.md)

选题依据、格式区别和候选池维护方式见 [模拟卷编制说明](docs/模拟卷编制说明.md)。
