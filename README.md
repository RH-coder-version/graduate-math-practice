# 研习题库

面向研一同学的**本地复习工具**，包含数值分析、数理统计和英语。下载到自己的电脑后即可离线刷题，无需注册；作答与错题记录只保存在自己的浏览器中。

![研习题库界面预览](docs/images/study-desktop-20261020.png)

## 题库内容

| 科目 | 资料组成 | 练习数量 |
| --- | --- | --- |
| 数值分析 | 历年试卷、模拟题、期末复习题及答案，覆盖误差、求根、线性方程组、插值、拟合、积分与微分方程等 | 364 |
| 数理统计 | 研究生试卷、复习题与扫描练习，涵盖概率基础、估计、检验、方差分析、回归与试验设计等 | 142 |
| 英语 | 《新探索》U1—U4 A/B 篇练习与讲稿，包含词汇填空、英译汉和句式分析 | 148 |

共 **654 道练习**，不同试卷中的重复题保留；英语句式分析由原资料讲解改编。

只想看 PDF、Word 或打印复习，也可以直接使用 **[原始资料清单与下载链接](sources/README.md)**，无需安装或运行网页。

## 可以怎么用

- **日常刷题**：按知识点或题库选择题目，先看知识背景与例题，再作答、展开 Markdown 详解。
- **知识图谱**：以节点连线图展示三科章节与核心考点，支持缩放、下载 SVG；点击节点查看方法与易错提醒，可标记自查并跳转练习。
- **查漏补缺**：标记错题与完成状态，保存解题笔记，集中复习薄弱部分。
- **考前突击**：使用精选题路线，或做模拟押题卷、按考点随机组卷，交卷后查看答案并自评。
- **调整界面**：默认西安工程蓝，可切换纯色主题、折叠侧栏与目录。

模拟卷依据现有资料编制，英语采用课程资料综合模拟格式，不代表真实考题。详细说明见 [考前突击选题清单](docs/考前突击选题说明.md) 和 [模拟卷编制说明](docs/模拟卷编制说明.md)。

## 本地启动

1. 点击本页 **Code → Download ZIP**，下载并解压整个项目。
2. 安装 **Python 3**（已有 Python 或 Anaconda 可跳过）。
3. 在项目文件夹中打开终端，运行：

```sh
python start.py
```

Windows 也可尝试 `py start.py`；macOS / Linux 可使用 `python3 start.py`。

浏览器会打开 **http://127.0.0.1:8931/**。这是自己电脑上的地址，不能发给同学直接访问；分享本仓库链接，让同学下载运行即可。前端依赖已附带，无需安装 npm 包，下载后可离线使用。使用期间保持终端打开，结束时按 `Ctrl+C`。

## 保存与备份

作答自动保存在当前浏览器，刷新后可继续。请保持使用同一浏览器和地址，并定期备份：

- 平时刷题：侧栏 **导出学习记录 / 导入记录**。
- 模拟与随机卷：组卷页 **导出试卷记录 / 导入试卷记录**，与平时记录独立。

清理浏览器数据、使用无痕模式或换电脑可能导致记录丢失。个人作答不会上传 GitHub，也不会与其他同学共享。
